# 更换宇宙背景

1. 将你有权使用的高清 JPEG 或 PNG 放到本目录。
2. 修改 `background.json` 中的 `file` 文件名、`label` 舷窗标题、`credit` 署名和 `source` 来源链接；同步更新 `CREDIT.md`。
3. 在工程目录运行 `npm run build`，然后重启独立预览。

建议横向照片。当前默认 `cosmic-horizon.png` 是 1672×941 艺术合成图，结合 M83、Westerlund 2 与 Webb 星云；它不是单一真实观测。另保留 4000 像素原始 `galaxy.jpg`、`westerlund2.jpg` 和 `nebula.jpg` 供替换。原始照片未改色或裁切，来源见 CREDIT.md。
构建器将图片内嵌进插件，运行时无需联网，不依赖不受 DSH 支持的 `/plugins/.../assets` 路径。
三个舷窗通过遮罩共同显示一张连续星景，背景暗化和程序星场由运行时合成；当前没有行星图层。缓慢、快速和极快三档控制巡航效果，极快档增加跃迁星轨。

`cockpit-frame.png` 为 1672×941 的 AI 生成舰桥金属外壳，无座椅。黑色窗口由主题 SVG 遮罩合成宇宙层，三个工作屏由真实 UI 透视嵌合到对应外壳，可分别悬浮和嵌回。图片只提供装饰，不包含聊天按钮、文本或假仪表数据。

“观察距离”与拖动视角使用统一船舱相机，同步控制舷窗、驾驶台和嵌合屏幕，外景景深不受距离控制；悬浮屏幕保持稳定。`cabin-titanium.png` 是侧墙、顶棚和地板使用的 1254×1254 金属材质；四面实体舱室在最大转角和远景下填充周边。首次启动默认缓慢巡航，飞行与视角偏好在浏览器中保存。速度和跃迁辉光约 2.4 秒达到新目标的 95%；停泊经过减速后停止绘制。控制面板默认收起。

更换驾驶台图片时，需要同时校准 `src/client/index.js` 的窗口遮罩与 `src/client/screen-docking.js` 的屏幕四角坐标；船舱几何由 `src/client/cabin-camera.js` 管理。
