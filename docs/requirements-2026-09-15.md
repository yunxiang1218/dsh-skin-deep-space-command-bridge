# 舰桥修正验收记录

用户在 2026-09-15 明确要求，后续开发必须保留这七点：

1. 观察距离改变人到整个前方船舱的距离，包含驾驶台和舷窗；最大距离不能出现未制作的黑边，周边舱壁、顶棚、地板需要有精致未来工艺细节。
2. 拖动视角观察整个船舱，不能只转动窗外背景；嵌入屏幕必须跟随相同空间坐标，原生交互继续可用。
3. 飞行速度、视角控制需要收起/展开按钮，收起后不挡舷窗。
4. 舷窗需要更高更大；工作完成后能够抬头看宇宙，工作时可回到驾驶台。
5. 结合 NASA/其他天文网站的真实照片制作更美的艺术星景；保留来源，艺术合成不能冒充单一真实观测图。
6. 缓慢、快速、极快的运动差异显著；极快为科幻跃迁效果；加速、减速及进入/退出跃迁需要缓冲过渡。
7. 持续提高景色动画品质：连贯、丰富、有纵深，避免突跳、循环接缝和无谓遮挡。

继续遵守：独立 dsh-theme-plugin；不改 DSH 核心或 maid-atelier；不显示座椅；三个舷窗景色连续；去除深色星球；三块工作屏独立按钮悬浮/嵌回，保留真实会话、草稿、模型能力和工作区功能。
