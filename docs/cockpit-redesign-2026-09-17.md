# 0.4.0 驾驶台造型重做记录

日期：2026-09-17。本文记录本次素材生成与接入依据，将已核实的素材事实和需要真实宿主验收的效果分开记录。

## 设计依据

用户提供了六张驾驶台参考，要求重新设计造型，去掉粗黑钢铁边，让美学、通透感和清晰度成为重点。本次采用纤细银色轮廓、大面积主窗、简洁弧形台面，以及冷石墨灰与缎面钛合金材质。结构只保留少量明确的接缝和细灯线，移除叠加梁、螺栓堆料与厚重装甲边框。

驾驶台保留三块空白深蓝玻璃屏：较宽的中央屏和两块侧翼屏。原生工作区、聊天和 AI 核心面板由 HTML 实时呈现；生成图不承担按钮、文字、假仪表或数据。整舱、嵌屏与舷窗继续使用同一观察相机，浮窗保留稳定的视口位置。

## 生成通道、参考与分辨率

使用内置 OpenAI Image Gen。当前工具没有可直接指定的模型参数或强制输出 4K 的参数。向用户说明限制后，用户明确选择“先完成现有通道的最佳效果”。本次没有转用外部 API，也没有插值放大后宣称原生 4K。

完整原始提示词、输入图片路径、生成日期和工具返回的本地输出路径保存在 [cockpit-v3-generation.json](../assets/resource/cockpit-v3-generation.json)。用户的六张参考用于确定造型方向，其中第 5、6 张作为实际图像输入；其余图片用于人工理解风格。驾驶台是在两张风格参考基础上新生成的场景，并非直接编辑某张参考原图。随后，以新生成的 `cockpit-frame-v3.png` 为参考生成钛合金材质。

驾驶台提示词要求正中驾驶员视点、近似对称构图、通透风挡、细银色结构、无座椅、无文字标识、空白显示屏和均匀近黑色窗外占位区域，实际星景由运行时透过遮罩呈现。材质提示词要求正交视角、大块缎面钛合金板、细接缝、均匀光照，并排除管线、成排螺栓、厚装甲、文字与太空景物。完整英文措辞以上述 JSON 为准。

## 接入范围与保留内容

- 构建入口改用两张 v3 素材，图片随插件内嵌，运行时无需联网下载。
- 根据新驾驶台重新校准舷窗遮罩和三屏四角投影；屏幕叠加细玻璃边缘，缩减装饰占用。
- 保留原生 DSH 编辑器、工作区、历史、模型选项和设置，以及既有三屏悬浮/拖动/嵌回、整舱观察、连续航速和随机换景逻辑。
- 外景默认使用四张 4000 像素宽的 Webb/Hubble/ESO 原片。「飞行控制 → 舷窗影像」可切回 0.3.0 的四种艺术全景。原片与合成图分开标识并保留来源；仅合成图属于艺术重构，航行动画均为视觉模拟。
- 移除外景额外缩放，将边缘余量从 10% 降为 4%；独立随机二维轨迹限制在横纵各 ±3%，三窗、星点、跃迁中心共用偏移。路径在每次转向的速度和加速度均连续，随航速缓动，并在隐藏/减少动态效果时暂停。
- `cockpit-frame.png`、`cockpit-frame-v2.png`、`cabin-titanium.png` 及旧全景保留为历史素材；[旧版美术记录](artwork-generation.md)、[星景记录](universe-scenes-generation.md) 和 [0.3.0 验证记录](verification-0.3.0.md) 继续保留。

## 0.4.0 验收范围

2026-09-18 最终收尾：74 项单元测试、GPU 背景像素验证及独立 DSH 宿主 `test-results/real-host-MyuCuB/report.json` 均通过。高清照片现由 Worker 解码并分条上传 GPU，补齐快速切换影像时的取消与故障回退。作者明确允许偶发轻微卡顿，以基本流畅为准；每帧最低 144 fps 不再作为阻塞验收项。下文 2026-09-17 的报告为历史记录，最新证据见 [0.4.0 验证记录](verification-0.4.0.md)。

素材尺寸、文件字节数、SHA-256、生成记录和当前构建的 v3 引用已核对。本节不将源码接入等同于完整浏览器验收。

已运行 `node scripts/host-smoke.mjs --hardware --headed`，最终本地报告为 `test-results/real-host-Jwmv6P/report.json`，报告版本 `0.4.0`、`success=true`，页面错误和失败请求均为空。该报告包含新版驾驶台、高清原片/艺术全景切换、随机航行及 4K 视口。使用 NVIDIA RTX 4090 Laptop GPU 的 D3D11/WebGL2，有窗口运行，未启用 `--uncapped`；`physical144HzVerified=false`。详细结果与限制见 [0.4.0 验证记录](verification-0.4.0.md)。

已复核最终报告对应的默认驾驶台、4K、抬头观景、拉远、左侧转头及三屏悬浮截图；边界由舱壁填充，三窗共享外景，工作屏保持嵌合。真实宿主检查覆盖上下左右转头、拉近拉远、草稿、工作区、模型与 Thinking 选项、原生设置、浮窗拖动及停用/恢复。早期 4K 截图曾出现底部驾驶台缺块；限制同时渲染的星景至当前图与渐变目标图后，最终 4K 截图未复现。4K 视口截图表示界面输出尺寸，不改变驾驶台素材的原生像素尺寸。

性能验收需要区分动画回调 CPU 耗时、rAF 调度间隔、浏览器合成/提交以及物理显示呈现。报告应注明硬件、分辨率、前台状态、刷新率、采样时长和异常帧。没有软件帧率上限、回调足够短或旧版约 240 Hz 的调度记录，均不能证明新版每一帧最低达到 144 fps。0.3.0 的测量只作为历史基线；0.4.0 的性能结论需要新版数据。
